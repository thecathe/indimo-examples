# AI Translation of Go FindAll Example

This example is directly taken from the [`indimo/examples/go/findall/run.go`](../../go/findall/run.go) and suits `go` far better. The `erlang` implementation is not very intuitive or standard, but serves as a (hopefully useful) reference point between the two languages.

> **Note:** Much of this was generated by AI as a blunt "proof of concept" as a test to see how useful it would be. *Turns out, not very much.*

## Run

```shell
make run safe   # 'safe' hardcoded preset
make run unsafe # 'unsafe' hardcoded preset
make run 3 2 1  # use n=1 m=2 k=3
```

## Implementation

Since the original example relies on the bounds of channels, and erlang has no such equivalent, this behaviour must be emulated. This is achieved by the record `chan` on line 7 of [main.erl](main.erl).

### Deadlock detection

If the main thread of a go program reaches deadlock, it can be detected. This is not the same for erlang, and so we use a "supervisor like" [sup.erl](sup.erl) that requires the main "thread" sends a `heartbeat` signal, which cannot occur if a deadlock occurs.
